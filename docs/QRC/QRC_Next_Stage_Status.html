QuestionRigorous answer
Do multimodal (18) carry signal?Yes — small but significant +ve marginal every horizon (+0.003…0.005, beats random null); standalone R²≈0.60 @ h30. v1 "useless" was wrong. Keep it.
Does phase (re+im) help?Structured (beats noise) but redundant — ~0 marginal over magnitude.
Does extracting more multimodal (136 vs 18) help?For multimodal itself yes — richer extraction ~doubles long-horizon skill (h45 CV 0.42→0.63); 18 was too few. But paired per-fold test shows no robust win over magnitude (mag wins h1/h10; long-horizon "wins" are 1–2 lucky folds). qrc_phase1_rich.py
Best representation? / dimensionality?No robust winner — magnitude wins short-range, long-range is a fold-variance coin-flip (±0.10–0.28). Signal low-dimensional (PCA-18 ≈ full 653).

Baseline horizon profile: h1=0.950 · h10=0.888 · h20=0.860 · h30=0.812 · h45=0.786. Decision gate (rigorously supported): representation choice is low-headroom (all reps ≈ equivalent when reduced; multimodal adds ~0.004) → prioritize Phase 2 (encoding) — NOT because "multimodal is useless" (it isn't).
